Link para clientes

------
Envie esse código para seus clientes. Eles colam na tela inicial do app para agendar com você.
Cole aqui o endereço onde o app do cliente está publicado na internet (o arquivo cliente.html). Preenchendo isso, o link compartilhado abre o app do cliente já com seu código preenchido — o cliente não digita nada.
Vai abrir o menu de compartilhar do seu celular — escolha WhatsApp → Status. Quando o cliente tocar no link, o app dele já abre pronto, com seu código preenchido, e um aviso pra adicionar o ícone na tela inicial.

👁️ Pré-visualização

Veja exatamente como fica o app para os seus clientes — cores, mensagem de boas-vindas e serviços já aparecem do jeito que você configurou. Use isso enquanto personaliza, para conferir o resultado antes de compartilhar com os clientes de verdade.
